# Pearle Estética Avançada by Eliana Abreu

Prévia do site (página única, HTML/CSS/JS estático) para a clínica Pearle, no Jardim Ester, São Paulo.

- `docs/`: o site, publicado pelo GitHub Pages como prévia (`noindex`, `robots.txt` bloqueando buscadores).
- Fotos: do Instagram @estetica.pearle, recortadas e otimizadas em `docs/assets/img/`.
- Para ver localmente: `python -m http.server 8611 --directory docs`.
